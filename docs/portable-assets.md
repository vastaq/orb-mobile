# 移动和桌面之间的资产

手机在「设置 → 本地资产」按名称或路径搜索，用筛选按钮选择类别，然后勾选并导出。筛选时点「全选结果」会把可见项加入已有选择。可以单独携带一份工作文件或一个技能。ZIP 解压后用编辑器、Codex 或任何能读本地目录的助手打开 `INDEX.md`。

| 位置 | 内容和修改方式 |
| --- | --- |
| `workspace/` | 用户的 UTF-8 工作文件，保留原始相对路径。可以直接编辑、建立子目录或添加文件，每个文件上限为 1 MiB。 |
| `.agents/skills/<id>/` | Agent Skills 格式的 `SKILL.md`，附带 `skill.json` 和原有文本参考资料。使用其他技能目录约定的桌面工具可以复制整个技能目录。 |
| `chats/INDEX.md` | 按标题进入会话索引，按对话顺序打开每条消息或对应附件。要带回修改，编辑链接指向的消息正文。 |
| `attachments/` | 原始附件，相同字节只存一份。聊天索引用原始名称链接；恢复清单记录原名和类型。 |
| `memories/`、`tasks/`、`prompts/` | 人能直接阅读和编辑的记忆、任务提示、个人指令与模板。索引列出选中任务的名称、周期和时间。 |
| `orb.json` | 手机恢复数据的清单。桌面助手阅读或编辑现有文件无需先解析它。 |

例如在电脑上编辑 `workspace/读书/周五.md`，新建 `workspace/读书/下次.md`，然后把原目录压回 ZIP。手机打开导入预览，展开「工作文件」可确认两个路径。未在手机修改的旧文件会更新；两端都修改过的文件会保留一份带「导入」后缀的副本。再次导入同一版会跳过已存在的内容。包内省略文件不会删除手机原件。

桌面可直接准备含 `workspace/` 或 `.agents/skills/` 的 ZIP，手机会发现其中的工作文件或技能。仅迁移这两类内容无需创建 `orb.json`。系统压缩产生的一层外目录也能打开。迁移 Orb 对话、记忆、任务与个人配置时应保留原清单。资产包新格式为 v2，手机仍可读 v1。旧版手机需先升级才能读取 v2。

多类资产同时导入时，个人配置初始未勾选。选中该类会应用名称、个人指令和同 ID 模板。相同的对话跳过，修改的对话另存。记忆按导出时的原文哈希匹配更新。导入的任务初始关闭，用户可以选择何时启用。

同来源、同 ID 的带版本技能通过提高版本号更新。来源不同、降级或同一版本内容相异时保留手机原版，处理结果会说明原因。新装技能恢复包内的启用状态，自动更新需在目标设备单独开启。本机已有的开关由本机保留。带查询参数的订阅或更新链接在迁移时移除，需要订阅时在目标设备重新配置。技能包内的文件与用户正文仍可包含作者自行写入的其他信息。

可选择 WinZip AES 密码保护文件内容。ZIP 目录和文件名对持有压缩包的人可见，工作区和技能目录会保留原始路径。解压目录中的内容为明文。
