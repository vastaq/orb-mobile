The archive contains the self-hosted wcc compiler, xcc C headers, startup
objects and C runtime library. The source Makefile builds wcc-gen2, wcrt0.a
and wlibc.a for Wasm.

To reproduce these two packaged files, download wccfiles.zip and verify the
archive checksum above. Run the following with Python 3 in the same directory.

    import base64, json, zipfile
    from pathlib import Path

    with zipfile.ZipFile("wccfiles.zip") as archive:
        Path("compiler.wasm").write_bytes(archive.read("usr/bin/cc"))
        sysroot = {
            "/" + item.filename: base64.b64encode(archive.read(item)).decode("ascii")
            for item in archive.infolist()
            if not item.is_dir() and item.filename.startswith(("usr/include/", "usr/lib/"))
        }
    data = json.dumps(sysroot, sort_keys=True, separators=(",", ":")) + "\n"
    Path("sysroot.json").write_bytes(data.encode("ascii"))
